# 👁️ Sight – 在家自己测视力

Sight 是一款轻量级、免设备的视力自测工具。利用手机屏幕与 5 米标准距离，通过精准校准视标尺寸，实现近似专业视力表的自测效果。

---

## ✨ 特点

- 📱 完全离线，无需网络，无广告
- 🎯 基于标准对数视力表原理（5 米 / 1.0 视标高度 **7.27 mm**）
- ⚙️ 手动校准，适配不同屏幕像素密度
- 📦 单 APK 文件，即装即用
- 🆓 免费开源

## 📏 校准方法（关键步骤）

### 测试视力值5.0（5分记录）/1.0（小数记录）的方法

为了确保 5 米距离下视标对应标准 1.0 视力，必须将屏幕上的 **“E”视标实际物理尺寸** 调整为 **7.27 mm**。

1. 打开 App，进入 **设置** 页。
2. 准备一把直尺（建议透明塑料尺，精度毫米级）。
3. 将手机平放，屏幕上会显示一个视标 **“E”**。
4. 点击 +/- 按钮，直到 **用尺子量得“E”的高度恰好为 7.27 mm**（请尽量平视，避免视差）。
5. 点击 **确认**再点击 **保存并返回** ，校准值会被记录。

或者
1. 打开 App，进入 **设置** 页。
2. 准备一把直尺（建议透明塑料尺，精度毫米级）。
3. 将手机平放，屏幕上会显示一个视标 **“E”**。
4. **用尺子**测量“E”视标实际物理尺寸输入到当前毫米尺寸。
5. 点击 **自动校准**再点击 **保存并返回**。

> 💡 小技巧：你可以通过 +/- 按钮调整“E”视标实际物理尺寸为整数例如50mm，再使用自动校准功能。

### 测试其他视力值（例如5.1/1.2、5.2/1.5）的方法

翻阅[标准对数视力表](https://www.nhc.gov.cn/wjw/pqt/201207/55375/files/1739781177940_56663.pdf)，找到 **表3 远视力表视标数据** 对应的 **视标边长** 调整视标大小即可。

## 🧪 开始测试

1. 将手机固定在支架上，或靠墙放置。
2. 确保屏幕亮度 **调到最高**。
3. 人眼与屏幕 **距离 5 米**（可提前用卷尺测量标记位置）。
4. 在主页点击 **开始** 按钮。
5. 遮挡住另一只眼睛。
6. 记住屏幕上“E”的方向，稍后会有箭头告诉答案。
7. 如果你能在5m距离看清7.27mm的视标“E”的方向说明你测试眼的视力有5.0/1.0。

---

## ⚠️ 注意事项

- **距离必须准确**：5 米是标准距离，过近/过远都会影响结果。
- **环境光线**：建议中等环境光，避免屏幕反光或过暗。
- **校准是灵魂**：每台手机的 PPI 不同，务必按上述方法手动校准至 **7.27 mm**（或查阅[标准对数视力表](https://www.nhc.gov.cn/wjw/pqt/201207/55375/files/1739781177940_56663.pdf)校准至你想要的大小）。
- **此工具为家庭自测参考，不能替代专业眼科检查。**
